# Reporting a security problem

If you find something that could expose files in a Dobr vault, please email **hello@dobr.app** with:

- what you found and how to reproduce it
- which version of Dobr you tested (Settings shows it), if you tested the app itself

Please don't open a public issue for it until a fix is out. We'll reply within a few days, keep you posted while it's being fixed, and credit you when it ships if you'd like.

Things that are already known and written up in [DESIGN.md](DESIGN.md), such as there being no lockout after wrong patterns and vault folders being visible to someone who can read the app's private storage, don't need reporting, though ideas for improving them are welcome.
